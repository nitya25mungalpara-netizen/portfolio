Catching bad invoices before the Italian government does

COSC2673 Machine Learning · 2026 High Distinction

Spotting cancer cells in colon tissue

Pathologists review slides by eye, which is slow, and they don't always agree. I trained models on 20,000 tiny cell images to tell cancerous cells from healthy ones, and to sort cells into four types.

  • Split the data by patient, not by cell, so the model is always tested on people it has never seen. A random split would have flattered it.
  • Built up from logistic regression to an MLP to CNNs, and added augmentation and class weighting only where I found a specific failure.
  • Noticed that in this dataset every epithelial cell is labelled cancerous, which explained which classes were easy and which were hard.
88% accuracy on patients it had never seen · graded HD

COSC2824 Cloud Operations · individual project · 2026

Keeping a café's website up on AWS, even when a server goes down

The brief: a fast-growing café chain needs its online presence to be scalable, secure and monitored. I built the whole AWS environment for it on my own, then checked every part from the command line rather than trusting the console.

  • A custom VPC across two availability zones, with public subnets for the load balancer and a bastion host, and private subnets for the web servers and database.
  • Web servers in an Auto Scaling group behind an Application Load Balancer, with RDS MariaDB, Parameter Store for configuration and S3 for static content.
  • CloudWatch alarms with SNS email alerts, CloudTrail audit logs and VPC flow logs. I also diagnosed and fixed a deliberately broken CloudFormation stack.
